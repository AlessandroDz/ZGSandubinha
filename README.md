# ⚔️ ZG Sandubinha RPG

Jogo de RPG desenvolvido em Java como teste técnico para um processo seletivo da ZG Soluções.

## 📖 Sobre o projeto

O projeto consiste em um jogo de RPG com narrativa própria, sistema de batalhas, itens especiais e desafios que exigem ações específicas do jogador.

O objetivo é explorar a história, utilizar os recursos disponíveis estrategicamente e cumprir uma sequência de condições e eventos para derrotar o chefe final.

O desenvolvimento seguiu os requisitos e a cronologia estabelecidos no desafio técnico proposto pela ZG Soluções.

## 🎮 Funcionalidades

- Sistema de batalhas.
- Narrativa e progressão da história.
- Sistema de itens especiais.
- Desafios com condições específicas para resolução.
- Eventos organizados por uma sequência cronológica.
- Batalha contra o chefe final.

## 🛠️ Tecnologias utilizadas

- Java
